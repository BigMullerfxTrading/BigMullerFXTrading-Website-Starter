# BigMullerFX Trading Website Starter

A modern, responsive starter website for a trading brand built with plain HTML, CSS, and JavaScript.

## Features

- Clean landing page layout
- Responsive navigation and hero section
- Trade-focused branding and messaging
- Mobile-friendly design
- Simple deployment-ready static site

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — main page content
- `styles.css` — site styling and layout
- `script.js` — small front-end enhancement

## Deployment

This starter is ready to be deployed to GitHub Pages, Netlify, or any static host.
